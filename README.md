# LearnIT

Free books, notes, syllabus and previous year question papers for Diploma in Computer Science and Engineering students.

Live at [learnit-io.vercel.app](https://learnit-io.vercel.app/)

## Contributing

To add or fix a resource, edit the matching file in `src/data/` (for example, add `{ "label": "...", "href": "..." }` to the right semester in `books.json`) and open a pull request.

To run locally, serve the folder over HTTP (for example with the VS Code Live Server extension) and open `index.html`.
